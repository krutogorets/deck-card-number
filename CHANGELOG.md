# Changelog

## 1.0.0 – 2026-10-30

- Первый релиз: новые карточки Deck получают префикс `#<id>` в заголовке.
- Слушатель `OCA\Deck\Event\CardCreatedEvent`; номер проставляется в том же запросе, что создаёт
  карточку, поэтому ответ API уже содержит заголовок с номером.
- Копии карточек перенумеровываются (чужой `#<id>` заменяется на актуальный).
- `tools/backfill.py` — нумерация существующих карточек через Deck REST API.
